## 凭证、代理与缓存

仅支持 DeepSeek：`deepseek-flash`、`deepseek-v4-pro` 均已真实调用。按用户选择未接入 OpenAI。浏览器不允许任意 Endpoint；连接测试只请求官方 /models，分析使用固定官方 /chat/completions，全部 HTTPS，上游禁止重定向。

Key 仅在当前页面内存，断开/刷新清除，不进入 IndexedDB、localStorage、sessionStorage、URL、训练备份或应用日志；同源服务器临时接触并转发密钥，界面明确说明。断开会中止前端请求，服务端收到连接关闭后中止上游传输；已经开始的供应商计算/费用不能保证撤销。

公共 BYOK 必须精确 HTTPS PUBLIC_ORIGIN，只信任回环 TLS 终结代理且 Host/Origin/协议均匹配；无跨域放行。缺少用户凭证直接 401，不回退开发者环境 Key。固定白名单、请求体 256000 字节、连接 12 秒/分析 35 秒超时、最多 2 并发、每凭证 12 次/分钟与代理总计 60 次/分钟；计数在内存中。错误不回显原始供应商响应。

训练事实、规则/解释版本、服务商、请求模型与分析维度进入缓存签名；读取时校验实际模型。不使用 Key 作为缓存 ID；实际返回模型不同则不复用该结果。规则继续在服务端重算并覆盖 nextAction，模型不能自行改变下一步重量处方。每次最多 0–2 条解释，不增加模型调用链。

## 验证结果

- 单元与 HTTP 安全测试：111 项通过，0 失败（原 95 项保留）。
- Playwright：49 项通过，0 失败（原 45 项保留）；覆盖 320/390 宽度、键盘缩短视口、刷新恢复、导出导入、计时器、离线、首次引导、规则反馈、静态版无 AI 请求、HTTPS BYOK 内存/错误/断开。
- TypeScript、静态 dist、私人 dist-local、BYOK dist-byok、服务端 dist-server 构建通过。Zod 的现有 PURE 注释提示不阻塞构建。
- 桌面 1440 与手机 390 实际界面检查：无横向溢出、无 pageerror；动作指导不遮挡开始记录。设计检测只提示原有字体使用，按保留视觉要求未替换字体。
- 真实官方 API：五类场景均 200；flash/pro 均返回同名实际模型；无效 Key 401、配置开发者 Key 但缺少用户 Key 仍 401。未将假响应冒充真实 API。浏览器自动化的模拟返回与真实供应商验证分别执行。
- API 端到端验证在本机回环代理上模拟已验证的 TLS 终结头，供应商 HTTPS 校验证书；浏览器 HTTPS 交互使用隔离自签测试证书。正式公网 HTTPS 未发布，不宣称已验证公网 BYOK。

## 真实生成文字

下列来自真实 DeepSeek 调用，输入为合成验收记录。单次下降复核后替换为最终提示词的真实输出，其余为同轮真实输出，未人工改写。

### same-load-more-reps · deepseek-flash

- 今天：杠铃卧推在60公斤下完成3组26次，比上次同重量多完成2次，计重工作量1560公斤·次；这是相同负重下完成量的实际增加。
- 解释：同重量多做次数说明这次完成量有提高，但单次变化还不足以确认力量或肌肉增长；先稳住这个表现，比急着加重更稳妥。
- 下次：暂不加重，先稳定重复本次表现。

### single-drop · deepseek-flash

- 今天：这次杠铃卧推在相同重量和组数下，比上次少完成1次，属于单次完成量的小幅波动；你仍完成了3组正式组，留下了可对比的记录。
- 解释：单次少1次暂不足以判断力量退步，也不等于进入平台期；先把它看作一次波动，下次同条件再观察是否稳定。
- 下次：下次先重复当前重量与组数，观察能否稳定完成。

### returning · deepseek-flash

- 今天：停训三周后，你主动记录并完成了杠铃卧推2组，为复训留下了真实起点。
- 解释：这次记录的价值在于重建基准，而不是和旧重量比高低。完成量变化不等于力量变化，先让身体重新适应训练节奏更重要。
- 下次：下次先以可控重量重建稳定表现，不补做中断期间的训练量。

### first-record-volume · deepseek-v4-pro

- 今天：杠铃卧推完成3组，每组8次，共24次，计重工作量1440 kg·次。
- 解释：这是首次记录，已留下训练起点。保留这个基准，之后才能看出同重量下的次数或组数变化。
- 下次：下次先用相同重量，尝试完成这次的组数和次数。

### stable · deepseek-flash

- 今天：杠铃卧推这次在60 kg下完成了3组8次，与上次相同，说明这个重量下的完成量保持稳定。
- 解释：相同重量、组数和次数都维持住，是当前训练基准稳定的表现，但不等于最大力量提升；单次持平也不代表长期趋势。
- 下次：下次先重复杠铃卧推 60 kg × 8 次 × 3 组，暂不增加负荷。
