# TrainTrace Coach

> 不是再给你一张练完就忘的通用课表，而是让 AI 根据你的真实训练记录，持续决定下一次怎么练。

[![Agent Skill](https://img.shields.io/badge/Agent-Skill-6C63FF)](./traintrace-coach/SKILL.md)
[![Codex](https://img.shields.io/badge/Codex-Compatible-10A37F)](https://openai.com/codex/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

一个面向力量训练的长期 AI 私人教练 Skill。它会记住你实际做过的重量、次数、组数和主观感受，再结合当天状态、训练目标、可用器械与时间，动态排课、复盘并调整后续训练。

**训练一次，记录一次；下一次建议就更像是为你制定的。**

## 它解决什么问题

普通 AI 健身建议往往停在一次对话里：每次都重新问目标，给出相似的通用课表，也不知道你上次究竟练了什么。

TrainTrace Coach 会在你的工作区维护一份本地训练档案，形成持续工作的闭环：

```text
了解你的目标和训练条件
        ↓
读取最近的真实训练记录
        ↓
结合当天状态安排本次训练
        ↓
记录实际完成情况并专业复盘
        ↓
用新数据调整下一次训练
```

它尤其适合这些时刻：

- “我今天只有 45 分钟，结合上次记录帮我练胸。”
- “腿还有一点酸，今天应该继续练还是换一个部位？”
- “卧推重量没增加，但比上次轻松，这算进步吗？”
- “我停练两周了，帮我保守地恢复训练。”
- “分析最近四周的记录，看看我卡在哪里。”

## 为什么值得安装

### 真实记录优先，而不是机械套模板

教练会读取最近训练的重量、次数、组数、RPE 和反馈，再决定当天安排。固定分化只是参考，真实训练历史才是依据。

### 不只生成计划，还会训练后复盘

它会区分计划与实际完成内容，判断本次是进步、稳定表现还是仅仅建立起点，并告诉你下一次应该保持、加量还是调整。

### 像教练一样临场判断

睡眠、疲劳、酸胀、器械占用、可用时间和训练意愿都会影响计划。信息不足时，它会给出保守的现场选重方式，而不是假装知道一个精确答案。

### 对新手友好，但不会把你当新手教一辈子

第一次遇到 RPE、训练量或记录方法时才解释；熟悉之后直接进入训练。首次使用通常只需 2–3 轮自然对话，不需要填写冗长问卷。

### 数据默认留在自己的项目里

个人档案与训练日志保存在当前工作区的 `fitness-coach-data/`，不会写进 Skill 安装目录。你可以随时查看、修改、备份或删除这些 Markdown 文件。

## 30 秒安装到 Codex

克隆仓库并复制完整的 Skill 文件夹：

```bash
git clone https://github.com/Cocobolo111-png/Personal-Fitness-Coach.git
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R ./Personal-Fitness-Coach/traintrace-coach "${CODEX_HOME:-$HOME/.codex}/skills/traintrace-coach"
```

重新启动 Codex，然后在准备保存训练记录的项目中发送：

```text
使用 $traintrace-coach 开始做我的私人健身教练。
```

如果曾安装旧版 `fitness-coach`，建议先确认其中没有自己的修改，再移除旧版，避免两个 Skill 同时被识别。已有的 `fitness-coach-data/` 训练档案无需改名，新版会继续读取。

## 使用起来是什么感觉

你不需要学习命令，也不必每次填写表格。自然说话即可。

### 第一次开始

```text
你：我想增肌，每周能练三次，平时在健身房，每次大约一小时。

教练：明白。我们会先建立一个可持续的训练起点，再根据每次真实完成情况调整。
为了安排第一节，还需要知道：你以前是否规律训练过，以及有没有会影响动作选择的不适或限制？
```

### 开启一次训练

```text
你：昨晚睡了 7 小时，腿还有一点酸，今天有 50 分钟，练什么？

教练：结合你最近的训练间隔，我更建议今天安排上肢拉，而不是继续堆下肢疲劳。
下面是一节 50 分钟内可以完成的背部训练……
```

### 训练后复盘

```text
你：卧推 60kg，8 次 × 3 组，最后一组 RPE 8；
上斜哑铃单边 20kg，10 次 × 3 组，最后两次有点不稳。帮我复盘并记录。

教练：已按实际完成内容记录。卧推与上次重量、次数相同，但末组 RPE 从 9 降到 8，
这说明同样工作量下你的完成余力提高了。上斜哑铃暂时不急着加重量……
```

回复会根据你的真实档案和记录生成，上面只是交互方式示意，不代表固定话术或预设结论。

## 能做什么

- 根据近期记录决定“今天练什么”。
- 在用户指定胸、背、腿、肩等训练方向时动态调整强度与容量。
- 给出动作、选重方式、次数、组数、目标 RPE、休息和成功标准。
- 接受自然语言训练记录，不强迫重复填写已经提供的信息。
- 对比同动作历史，识别负荷、容量、RPE 和动作感受的变化。
- 处理停训后的保守复训，以及普通训练酸胀下的灵活调整。
- 分析最近数周训练，判断进展、停滞和当前重点。
- 在真正需要时渐进解释 RPE、训练量和渐进负荷等概念。

## 它刻意不做什么

- 不把一套固定 PPL、胸背腿肩或“最佳模板”机械套给所有人。
- 不伪造用户没有提供的训练数据，也不把计划内容当成实际完成。
- 不把每次普通训练夸张包装成突破。
- 不用一次状态好就同时大幅增加重量、次数和组数。
- 不进行医学诊断、治疗或康复处方；出现明显异常症状时会停止常规训练建议，并提醒寻求适当的专业帮助。

## 训练数据如何保存

首次获得足够信息后，Skill 会在当前工作区建立：

```text
fitness-coach-data/
├── profile.md               # 相对稳定的目标、经验、器械和限制
├── coaching_preferences.md  # 沟通、排课和记录偏好
├── current_status.md        # 当前阶段与近期状态摘要
└── training_log.md          # 真实训练事实，持续追加
```

这些文件属于使用者，不属于 Skill。若当前项目会上传 GitHub，建议把 `fitness-coach-data/` 加入 `.gitignore`，除非你明确希望公开个人训练数据。

## 适合谁

- 想让 AI 记住长期训练记录，而不是每次从零开始的人。
- 希望计划能随状态和实际表现调整的力量训练者。
- 不熟悉训练术语，但愿意通过真实训练逐渐学习的新手。
- 已经有训练经验，想系统追踪 RPE、容量和渐进变化的人。
- 希望自己的健身数据以透明 Markdown 文件保存在本地的人。
